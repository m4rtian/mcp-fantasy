MCP Fantasy

A private fantasy football assistant for one Yahoo Fantasy Sports account, built to support informed lineup and waiver decisions.

What it will do

A locally run Model Context Protocol (MCP) integration will retrieve authorized fantasy league settings, rosters, matchups, standings, player statistics, available players and transaction history. An AI assistant will use that information to provide lineup analysis and weekly waiver recommendations.

Access and privacy

The planned integration requests read-only access through Yahoo authorization. It will not submit waiver claims, execute trades or change lineups. The intended user is the project owner; this is not a public or commercial service.

Credentials and authorization tokens will be kept locally and excluded from this public website and its repository. Relevant fantasy data will be shared with the owner's AI assistant for analysis, subject to that service's data policies. This informational page contains no analytics, login form or account data.

Project status

In development. Yahoo Fantasy API access and integration security review are pending. This page does not provide a working account connection.
