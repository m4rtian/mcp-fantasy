MCP Fantasy

A read-only fantasy football assistant designed to turn authorized Yahoo league context into clearer lineup and waiver decisions.

Early development

What it will analyze

  • League settings and standings
  • Rosters and weekly matchups
  • Available players and statistics
  • Recent transaction history

What it will never do

  • Submit waiver claims
  • Drop or trade players
  • Change a starting lineup
  • Expose credentials or league data

Planned workflow

The integration is intentionally small and local. It retrieves only authorized fantasy context and presents recommendations for the owner to review.

Yahoo APIRead-only data → Local MCPSelected context → AI assistantReasoned guidance → OwnerFinal decision

Privacy by design

OAuth credentials and tokens stay local. This public repository contains only this informational site—no private integration, account identifiers, rosters, or league data.

Yahoo API access and the integration security review are still pending. There is no working account connection on this page.
